Account migration safe

Google account, OAuth client, Drive folder and admin allow-list are deployment environment values. Moving the repository to another GitHub account does not require changing application ownership in source code.

Security model

Admin URL obscurity is only a secondary layer. Google OAuth, allow-list authorization, HttpOnly secure sessions, server-side Drive access, validation and rate limits are required for production.
